## 1. QA Root Cause Analysis
During BACK QA review of `T-HUB-104-plan-path-classifier-dedup`, full test suite execution revealed 5 failures across two test modules outside the epic's immediate refactoring scope:

- 1 failure in `loop/tests/test_hub_link_harness.py` (`test_product_settings_hook_paths_resolve`).

**Root Cause:**
Committed `.claude/settings.json` was locally modified with obsolete individual hook scripts (`agent-pretool.py`, `bash-pretool.py`, `write-pretool.py`, `finish-boundary-pretool.py`, `agent-posttool.py`, `bash-output-cap.py`) under `PreToolUse` and `PostToolUse` event matchers. These scripts were previously consolidated into `pretool-dispatch.py` and `posttool-dispatch.py` as declared in `harness/manifest.yaml`. The presence of obsolete hook entries in `.claude/settings.json` broke duplicate realpath checks, entry count limits, canonical dispatcher assertions, and product linking tests that assert resolved hook file existence.
