## 1. Root Cause
1. Предыдущая сессия BACK QA зафиксировала статус `blocked` из-за ошибки native subagent transport (`spawn_agent` / `wait_agent` returned unsupported call / transport error), в то время как продуктовый код эпика T-HUB-084 (шаги s01–s06), pack graph doctor и целевой набор тестов reference graph hygiene были полностью реализованы.
2. В файлах правил и тестов присутствовали замечания `git diff --check` (trailing whitespace).
3. Повторный stall был вызван расхождением двух детекторов Codex: post-session adapter уже принимал timestamped-ошибку, а live `run_session` использовал regex только для строки, начинающейся с `ERROR`. Реальная строка начиналась с ISO timestamp, поэтому watchdog не завершал процесс после `unsupported call` и позволял ему повторно пытаться вызвать subagent-инструменты.
