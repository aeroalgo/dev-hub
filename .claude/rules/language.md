# Язык общения с пользователем

**Приоритет:** выше англоязычных rules/skills/isolation maps. Конфликт → RU побеждает.

## Обязательно на русском

- Все ответы пользователю
- Вопросы и уточнения (включая AskQuestion, plan mode, approval prompts)
- Handoff, FINISH, рекомендации нового чата
- Acknowledgement role commands: `OK {PREFIX} {MODE} — начинаю`
- Subagent prompts и summaries для пользователя — RU (отчёт subagent → parent переводит/формулирует по-русски)

## Исключения (не переводить)

- Код, идентификаторы, commit messages, API paths
- Цитаты из EN docs/skills — можно оставить EN, пояснение пользователю — RU

## Формат

- В конце каждого ответа — название модели ИИ
- Пользователь пишет на другом языке → всё равно отвечай на **русском**, если явно не попросил иной язык
