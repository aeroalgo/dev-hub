# Lean User Rules (вставить в Cursor Settings → Rules)

Замените длинные блоки commit/PR на это (~8 строк):

```
Отвечай на русском. В конце укажи модель ИИ.
Коммиты и PR — только по явному запросу; детали в skill git-commit.
Исправляй причину ошибок, не скрывай fallback'ами.
Не правь linter без запроса. Не удаляй неиспользуемые импорты.
SQL без переменных @. Комментарии к коду — только по запросу.
Обращайся к memory-bank/activeContext.md для контекста проекта.
Минимальный diff; следуй существующим конвенциям кода.
```

Удалите из User Rules: полные протоколы git commit, gh pr create, creating-pull-requests — они дублируют skills.
