# Skill: video-pipeline

Когда пользователь просит фазу или «сделай ролик»:

1. Прочитай `AGENTS.md` + `work/project.yaml` + актуальный brief.
2. Определи `phase` и что ещё не закрыто.
3. Обновляй только нужные shot’ы.
4. После изменений — коротко статус: phase, сколько pending/image_ok/video_ok, blockers.
5. Не выдумывай медиафайлы: либо MCP/CLI создал файл, либо status=`blocked`.
